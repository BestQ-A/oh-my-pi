proc://<id>/streams lists a bash job's pipes, proc://<id>/streams/<n> reads what crossed pipe n so far. proc://<id>/model reads a subagent's active model; writing it a model selector switches a running, failed, or parked subagent mid-flight and continues (extra lines steer the continued turn); write agent://<id>?model=<model> is equivalent, its whole content being the message. Write sends stdin to services only (empty = Enter); proc://<id>/mode: persist|session|detached (services only); start long-lived work as a named service when it needs stdin or lifetime controls. Completed jobs are evicted, and job IDs stay process-local; delivered results expire shortly (~30s), unconsumed results within ~5min, while agent output and transcripts stay readable at agent://<id> / history://<id>.
